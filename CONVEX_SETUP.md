# Convex Setup Guide

## Quick Start

### 1. Install Dependencies
Already done! Convex is installed.

### 2. Start Convex Development Server

```bash
npx convex dev
```

This will:
- Start the Convex development server
- Create a new Convex project (if first time)
- Generate a `.env.local` file with your `VITE_CONVEX_URL`
- Watch for changes to your Convex functions

### 3. Migrate Data

Run the migration script to populate your Convex database with existing data:

```bash
# Make sure convex dev is running first!
node scripts/migrateToConvex.js
```

This will import:
- ~500 Spotify songs
- Drinking Buddy questions
- Never Have I Ever questions
- Truth or Dare questions
- Wildcards and New Rules

### 4. Add Convex Provider to Your App

Update `src/main.tsx`:

```typescript
import React from "react";
import ReactDOM from "react-dom/client";
import { ConvexProvider, ConvexReactClient } from "convex/react";
import App from "./App";
import "./index.css";

const convex = new ConvexReactClient(import.meta.env.VITE_CONVEX_URL);

ReactDOM.createRoot(document.getElementById("root")!).render(
  <React.StrictMode>
    <ConvexProvider client={convex}>
      <App />
    </ConvexProvider>
  </React.StrictMode>
);
```

### 5. Use Convex in Your Components

Example: Create a room

```typescript
import { useMutation, useQuery } from "convex/react";
import { api } from "../convex/_generated/api";

function CreateRoom() {
  const createRoom = useMutation(api.rooms.createRoom);
  
  const handleCreate = async () => {
    const { roomId, code } = await createRoom({
      hostId: userId,
      hostName: userName,
      gameMode: "classic",
    });
    
    console.log("Room created:", code);
  };
  
  return <button onClick={handleCreate}>Create Room</button>;
}
```

Example: Subscribe to room updates

```typescript
import { useQuery } from "convex/react";
import { api } from "../convex/_generated/api";

function Room({ roomId }) {
  // Automatically updates when room changes!
  const room = useQuery(api.rooms.getRoom, { roomId });
  
  if (!room) return <div>Loading...</div>;
  
  return (
    <div>
      <h1>Room: {room.code}</h1>
      <p>Players: {room.players.length}</p>
      <ul>
        {room.players.map((p) => (
          <li key={p.id}>{p.name} {p.isOnline ? "🟢" : "🔴"}</li>
        ))}
      </ul>
    </div>
  );
}
```

## Environment Variables

Add to your `.env` file:

```bash
# Convex
VITE_CONVEX_URL=https://xxx.convex.cloud  # Auto-generated by npx convex dev
```

## File Structure

```
convex/
├── schema.ts          # Database schema
├── rooms.ts           # Room management functions
├── game.ts            # Game logic functions
├── songs.ts           # Song queries
├── questions.ts       # Question queries
├── seed.ts            # Data seeding functions
├── crons.ts           # Scheduled jobs
└── tsconfig.json      # TypeScript config

scripts/
└── migrateToConvex.js # Migration script

_generated/           # Auto-generated (don't edit!)
├── api.ts            # API types
├── dataModel.ts      # Data model types
└── server.ts         # Server types
```

## Common Operations

### Create a Room
```typescript
const { roomId, code } = await createRoom({
  hostId: "user123",
  hostName: "Alice",
  gameMode: "classic",
  language: "en"
});
```

### Join a Room
```typescript
await joinRoom({
  code: "ABC123",
  playerId: "user456",
  playerName: "Bob"
});
```

### Draw a Card
```typescript
const { type, card } = await drawCard({ roomId });
// type: "song" | "question" | "wildcard"
// card: song/question/wildcard object
```

### Subscribe to Room Updates (Real-time!)
```typescript
const room = useQuery(api.rooms.getRoom, { roomId });
// Automatically updates when anyone modifies the room!
```

## Troubleshooting

### Issue: VITE_CONVEX_URL not set
**Solution:** Run `npx convex dev` first, it will generate the URL

### Issue: Module not found errors
**Solution:** Make sure convex dev is running to generate types

### Issue: Data not appearing
**Solution:** Check Convex dashboard to verify data was seeded

### Issue: Real-time updates not working
**Solution:** Check that ConvexProvider wraps your app in main.tsx
